Table JSON — Dados brasileiros em JSON

O Table JSON é uma fonte gratuita de dados de referência do Brasil em formato JSON, prontos para serem consumidos em qualquer aplicação. Aqui você encontra endpoints com dados do IBGE (municípios, UF, DDD e DDI), tabelas de impostos (CFOP, CNAE, ICMS, CSOSN, CRT), serviços (Simples Nacional e ISSQN municipal), países, moedas, cores, unidades de medida e dados de pessoas. Basta acessar a URL de cada conjunto de dados abaixo para obter o JSON.
